# 터치 순서 4 (갤럭시 자동 클릭 앱)

설정된 순서 `①→②→③`를 원하는 횟수만큼 반복합니다.

## Android Studio에서 설치 APK 생성
1. Android Studio에서 이 폴더를 **Open**으로 엽니다.
2. SDK 설치 및 Gradle Sync가 완료되면 **Build > Build Bundle(s) / APK(s) > Build APK(s)**를 누릅니다.
3. `app/build/outputs/apk/debug/app-debug.apk`를 휴대폰에 옮겨 설치합니다.
4. 앱 실행 → **접근성 서비스 켜기** → 설치한 `터치 순서 4` 서비스를 허용합니다.
5. 클릭 간격·묶음 대기 시간·총 반복 횟수를 입력하고 **클릭 위치 표시 / 설정 적용**을 누릅니다.
6. 대상 앱을 열고 화면 위의 ①②③을 원하는 곳으로 드래그합니다. 떠 있는 ▶ 시작 버튼으로 실행하고 ■ 중지/닫기로 중단합니다.

## 주의
- 개발용 예제이며 갤럭시 S26 실기기에서 테스트하지 않았습니다.
- 실행 중 표시 원은 터치를 통과하도록 바뀝니다. 중지하면 다시 이동할 수 있습니다.
- 접근성 서비스는 화면 내용이나 개인정보를 읽지 않습니다.
- 게임 정책 또는 일부 보안 화면에서 이용이 제한되거나 터치가 무시될 수 있습니다.
- 앱 종료·화면 꺼짐·접근성 서비스 해제 시 실행이 중단될 수 있습니다.

## GitHub Actions로 APK 만들기 (PC에 Android Studio가 없을 때)
1. 이 폴더 내용을 GitHub 새 저장소(루트)에 업로드합니다.
2. **Actions → Build APK → Run workflow** 실행.
3. 완료 후 Artifacts의 `TouchSequence4-debug-apk`를 내려받아 압축을 풀면 `app-debug.apk`가 있습니다.

## 갤럭시에서 설치/권한 팁
- 설정 > 보안 및 개인정보 보호 > **자동 차단(Auto Blocker)** 이 켜져 있으면 APK 설치가 막힙니다. 설치하는 동안 끄세요.
- 접근성 서비스가 회색으로 비활성화되어 있으면: 설정 > 애플리케이션 > 터치 순서 4 > 우측 상단 ⋮ > **제한된 설정 허용** 후 다시 시도하세요.
